# 友成商務空間 vs 聚創空間（喵爸）網站比較

比較日期：2026-11-07
- 友成：https://evolution0209-lang.github.io/taoyuan-meeting-room/head-office-rental.html
- 聚創：https://space.cathome.tw/?lang=zh-TW

## 總結
友成的網頁**內容其實已經很完整**：有月曆、線上試算、預約表單、守則、停車資訊、手機底部按鈕，這幾點和聚創差不多。
差距主要不在「有沒有」，而在**「讓客人更放心、更快下決定」**這幾點：LINE 詢問、預約流程說明、退費彈性、多時段優惠、照片載入速度。

## 逐項比較

| 項目 | 友成（我們） | 聚創（喵爸） | 誰比較好 |
|---|---|---|---|
| 首屏標語 | 「桃園中平商務教室租借」＋4 個按鈕 | 一句好記的口號「一個時段，就能開場」＋只放 2 個主按鈕（立即預約／加 LINE） | 聚創 |
| 首屏數字亮點 | 有（30–40人、8–10人、3時段、自助式），但放在第二段 | 首屏就秀：90人、3投影幕、2會議室、全日9折 | 聚創 |
| LINE 詢問 | 只有電話，表單裡有 Line ID 欄位，但**沒有官方 LINE 按鈕** | 官方 LINE 出現在首屏、頁尾、浮動按鈕三個地方 | 聚創（差距最大） |
| 價格呈現 | A案每時段 4,000、B案 1,500，清楚 | 依人數分級（1–30人 1,500／31–60人 1,800／61–90人 2,300），起價看起來更低 | 各有優點 |
| 多時段優惠 | 沒有，三時段就是 12,000 | 白天兩時段、全日三時段都打 9 折 | 聚創 |
| 預約流程 | 「送出不代表預約完成，需工作人員確認」，客人不知道下一步是什麼 | 「預約四步，全程不用打電話」：線上預約即保留 → 3天內匯款 → 回報後五碼 → 前一天寄進場說明 | 聚創 |
| 取消退費 | 正式預約後**不退費**，可延期一次 | 14天前全退，之後分級遞減，最多扣 30%；天災全退 | 聚創（影響信任感） |
| 怎麼到現場 | Google 地圖＋3 個周邊停車場 | 一步步說明「面對哪裡、走哪個門、搭電梯上3樓」，停車場寫怎麼繳費 | 聚創 |
| 適合活動 | 寫在場地描述裡 | 獨立一區用圖示列出 8 種活動 | 聚創 |
| 設備說明 | A案含音響、無線麥克風、HDMI，很完整 | 列出投影機、麥克風、桌椅數量 | 友成 |
| 聯絡管道 | 市話＋教室聯絡人手機，有真人感 | 只有 LINE | 友成 |
| 發票資訊 | 表單有發票抬頭、統編、寄送地址 | 只說事後郵寄 | 友成 |
| 可預約時段 | 月曆直接看到 A/B 案已預約、暫保留 | 另外頁面查看 | 友成 |
| 地點等級 | 18樓商務大樓 | 3樓、入口要找 | 友成（可以多強調） |
| 多語系 | 只有中文 | 中、英、日、越、韓 | 聚創（優先度低） |
| 照片載入速度 | 16 張 JPG 共約 14MB，每張 0.5–1.4MB，手機開會慢 | — | 我們需要改善 |
| Google 搜尋結構化資料 | 沒有 LocalBusiness 結構化資料 | — | 我們可以補 |

## 我們的優勢（要保留、可以多強調）
1. 18 樓商務大樓，形象比較專業
2. 40 人大教室附音響＋無線麥克風，講師只要帶筆電
3. 有真人電話可以問
4. 月曆直接看得到空檔
5. 發票、統編一次填好，適合企業客戶

## 需要老闆決定的事（屬於經營決策，不是網頁技術問題）
- 要不要開官方 LINE 帳號？（已經有的話，給我 LINE ID 就能加上去）
- 要不要做多時段優惠（例如全日 9 折）？
- 退費規則要不要放寬成分級退費？
- A案要不要依人數分級計價，讓起價看起來更親民？
